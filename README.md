## What I do

- **Robot software (FRC 9427):** Java + WPILib, Command-based. Per-mechanism PID, measured tuning, a tuning backend for the team. 2026 New Taipei Freshman Cup: alliance champion.
- **Developer tools:** things I need myself first. memrot came out of running an AI assistant on real projects for months and watching its notes rot.
- **Learning in public:** Python → APCS, then Java and systems.

## Principles

- Start from a real person's problem, interview first, guess later.
- Measure, don't assume. Tuning values come from tests, not from formulas.
- Write down what was done and what is next, so the next session (or teammate) never starts from zero.
